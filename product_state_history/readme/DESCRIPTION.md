This module extends **Product State** so that a product's state can no longer be changed by clicking the status bar.

A **Change State** wizard asks for the new state and a mandatory reason. Only users in the **Change Product State** group can see the button and change the product state. Each change is stored in a dedicated **State History** list on the product, not in the chatter.

Use this when you need an audit trail of product lifecycle changes (who, when, from/to, why).
