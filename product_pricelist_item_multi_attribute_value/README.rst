This module allows to add multiple price by attribute values to a product pricelist item.
It is useful when you want to set different prices for different combinations of attributes.

**Table of contents**

.. contents::
   :local:

Usage
=====

* select a pricelist item applied on a product
// * add multiple attribute values with prices
// * save the pricelist item
// * the prices will be applied to the product based on the selected attribute values
