This module allows to compute alerts on product lots for other fields
than expiration date (in product_expiry Odoo module).

Use Cases / Context
===================

For the time being, Odoo is computing an alert field for
``expiration_date`` one that has its date before as today.

In some warehouses, we need to get the lots that have the other fields
'expired' (date before today):

- Removal date
- Alert date
- Use Date

Usage
=====

- Go to Inventory > Products > Lots/Serial Numbers

- Choose the filter you want (Exipration/Removal/Use Date) to search for
  such lots.

- Go to Inventory > Products

- On the product form, go to On Hand shortcut.

- You can filter available quantities on different expiration fields.

- Enable debug mode and then go to Inventory > Reporting > Locations

- Then, use the filter you want on the entire stock.
