This module adds a 'Pricelist items' list view that allows to select
several elements to version them and also to see the percentage 'fixed
price' variation between a version and the previous one.

A 'Revise Prices' button on the pricelist form applies the same
revision to all the fixed price items of the pricelist at once (e.g. a
yearly price indexation), optionally limited to a product category.
