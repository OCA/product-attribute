To configure pricelists with the new feature of this module, you need
to:

1.  Create or edit a Sales Pricelist at *Sales \> Products \>
    Pricelists*.
1.  Add or edit a pricelist item and check "Formula" option in "Price
    Computation" section and set **Discount Type** to "By range".
1.  You will see the new option "Discount Ranges".
1.  Add discount ranges and save Pricelist.
