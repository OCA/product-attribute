1. Go to *Settings > Attribute Templates*.
2. Create one or more attribute templates.
3. Open a product.
4. Select one or more templates in the **Attribute Templates** field.
5. The corresponding attribute lines will be automatically added.

If the template is changed before saving the product, any non-saved
attribute lines previously added will be removed and replaced with the
attributes of the newly selected template.

To combine several templates, save the product before selecting another one.
