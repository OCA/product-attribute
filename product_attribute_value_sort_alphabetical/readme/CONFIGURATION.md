Go to *Sales > Configuration > Products > Attributes* (or *Inventory >
Configuration > Products > Attributes*) and open an attribute:

- **Sort Values Alphabetically**: enable the automatic alphabetical sort of
  the values.
- **Sort Alphabetically On**: the field of the values used to sort them
  (*Name* by default).
- **Keep Manual Sort**: safety lock. When checked, the sequence of the values
  is frozen and can be changed manually with the drag and drop handle, even if
  the alphabetical sort is enabled.

Disabling the alphabetical sort keeps the last computed order, which can then
be changed manually.
