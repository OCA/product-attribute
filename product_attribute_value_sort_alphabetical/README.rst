This module allows to sort the values of a product attribute
automatically in alphabetical order.

When the option is enabled on an attribute, the sequence of its values
becomes computed and is updated each time a value is added, renamed, or
when the field used for sorting changes. The drag and drop handle is
then replaced by the computed sequence in the list of values.

Usage
=====

Once the alphabetical sort is enabled on an attribute, simply add or
rename values: their order is updated automatically.

To sort on another field, extend the selection of the sort field in a
custom module:

.. code:: python

   class ProductAttribute(models.Model):
       _inherit = "product.attribute"

       @api.model
       def _selection_sort_field(self):
           return super()._selection_sort_field() + [("code", self.env._("Code"))]
