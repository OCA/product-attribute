Go to Settings \> Technical \> Database Structure \> Product Stickers.
You can add Stickers to Attributes resulting in different behaviours:
- If a Sticker has no Company, it is available to Products in all Companies.
- If a Sticker has no Attribute, it is available to Products with any Attributes.
- If a Sticker has no Attribute Value, it is available to Products with any
Attribute Values of the Attribute.
- If a Sticker has no Category, it is available to Products in all Categories.

You can mix behaviours to create a very flexible sticker system
