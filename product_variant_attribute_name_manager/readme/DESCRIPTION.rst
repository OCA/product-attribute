Manage how to display the attributes on the product variant name in the breadcrumb and in the browser title (html title). Currently not on the POS interface neither on the website. The default is to display the attribute value on the product variant name.

* Choose if you want to display the attribute value in the product name (default).
* Choose if you want to display the name of the attribute before its value.
* Set a short name to be displayed as the attribute's name.
* Set the order of the attributes for each product.
* Choose if you want to display attribute value name for Single Variant Attribute
