This module lets you write rules on a product template to control which
variants are generated from its attributes.

Each rule is made of:

- **preconditions:** attribute values that must be matched for the rule
  to apply. An empty precondition means the rule always applies.
- **type:** "Only With" keeps the combinations matching the
  postconditions, "Never With" removes them.
- **postconditions:** values the combination must (or must not) contain.

In preconditions and postconditions, values of the same attribute are
**ORed** while values of different attributes are **ANDed**.

Usage
=====

1. Open the product template and go to the *Attributes & Variants* tab.
2. Tick **Use Attribute Rules**.
3. Add your rules (preconditions are optional) and choose their type.
4. Save the product: the variants are generated again according to the
   rules.

A rule like:

   "All products with blue or green color in XL size will appear only
   with a V neck collar and a short sleeve."

is written as:

.. code:: text

   Preconditions: (color: blue), (color: green), (size: XL)
   Type: Only With
   Postconditions: (collar: V neck), (sleeve: short)

When the preconditions are empty the rule always applies. To only keep
the variants with a short sleeve:

.. code:: text

   Preconditions: (none)
   Type: Only With
   Postconditions: (sleeve: short)

To remove all the variants with a sailor collar:

.. code:: text

   Preconditions: (none)
   Type: Never With
   Postconditions: (collar: sailor)

When several rules are defined, they are ANDed together.
