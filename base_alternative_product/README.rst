This module allows you to define alternative products for a specific
product.

The alternative products relation is bidirectional, if a product A has a
product B as an alternative, the product B would also have product A as
an alternative.

This module is for general purpose, it is intended to be extended for
another modules f.e.: purchase_alternative_product, a module that
suggest the product alternatives in a purchase order.

Configuration
=============

To configure wich users will be able to edit product alternatives:

1. Go to Settings / Users & Companies / Users
2. Select your desired user
3. Set the "Manage Alternative Products" group, it only can be seen with
   the debug mode

Usage
=====

To use this module, you need to:

1. Go to a product variants form
2. In the "Alternative Products" tab, select the alternative products.
